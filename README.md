# Bingo Corporate — live demo

A clickable simulation of Bingo Corporate by HALO Studio: the manager, employee and driver apps and the owner console, running on one simulated engine in the browser. No backend and no real data.

- **Live demo:** https://halotechstudio.github.io/bingo-corporate-demo/
- **Product guide (PDF):** https://halotechstudio.github.io/bingo-corporate-demo/Bingo-Corporate-by-HALO-Studio.pdf

Tabs: **Live demo** (full ride cycle), **Onboarding** (company, manager, employee and driver sign-up), **All screens** (every screen).
